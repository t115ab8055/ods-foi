# lab-crawler-ods-foi

以 Python 擷取[金融消費評議中心評議決定書查詢系統](https://ods.foi.org.tw/)的列表資料與文件連結，匯出 CSV；不下載決定書全文。

## 執行方式

需安裝 Python 3.14 以上版本與 uv，在專案目錄執行：

```bash
uv sync
uv run python main.py
```

程式將全年日期切成每段最多 31 天的區間查詢。遇到超過 100 筆的提示時，依序按產業、子產業、爭議類型細分查詢，再合併結果並重新編號。

輸出為目前工作目錄下的 `評議決定書.csv`，使用 UTF-8 BOM 編碼，方便 Excel 開啟。每次執行會覆寫同名檔案，CSV 已列入 `.gitignore`。

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `main.py` | 日期分段、整合結果與 CSV 匯出 |
| `servers.py` | 分層查詢流程 |
| `api.py` | 網站請求與分類選項取得 |
| `crawler.py` | HTTP 標頭與查詢表單參數 |
| `parse.py` | HTML 表格解析與筆數上限提示判斷 |

## 目前限制

- 查詢年份在 `crawler.py` 的 `txt_Syear`、`txt_Eyear` 固定為民國 `115` 年（2026 年）；更換年度需同步檢查 `main.py` 的日期區間設定，目前沒有命令列參數。
- 細分至爭議類型後若仍超過 100 筆，不會繼續分割或翻頁，因此不保證資料完整；目前也未去重。
- 表單狀態值與 HTML 選擇方式寫在程式內，網站改版時可能需要調整；請求失敗會中止，尚無自動重試或續跑機制。
